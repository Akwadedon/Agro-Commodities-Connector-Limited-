# Agro-Commodities Connector Limited

## Connecting Nigerian Agricultural Commodities to Global Markets

Agro-Commodities Connector Limited is a Nigerian agro-commodities trading, sourcing, export, import and B2B supply company.

- **CAC:** 9717504
- **NEPC Exporters' Registration Number:** 004960
- **Country:** Nigeria
- **Email:** agrocomconltd@gmail.com

## Website

This repository contains the official website project for Agro-Commodities Connector Limited.

The website is designed as a professional corporate website and B2B agricultural commodity marketplace foundation for buyers, suppliers, traders, importers and exporters.

## Current Features

- Responsive professional homepage
- Company information and registration details
- Agricultural commodity marketplace
- Commodity search and category filtering
- Buyer section
- Supplier section
- Request for Quotation (RFQ) form
- Trade tools and resources
- Export documentation information
- Professional video placeholder
- Responsive mobile navigation
- Email-based enquiry workflow

## Security

Never place a Supabase secret or service-role key in front-end code.

Only appropriate public/publishable credentials should be used in browser applications, with database and storage security policies configured correctly on the backend.

## Brand

The official Agro-Commodities Connector Limited logo and approved company identity should be used throughout the final website.

## Vision

To become a trusted digital hub connecting Nigerian agricultural commodities with businesses and buyers around the world.

## Mission

To make agricultural commodity sourcing from Nigeria more accessible, transparent and reliable by connecting buyers with quality-focused suppliers and supporting efficient international trade.
